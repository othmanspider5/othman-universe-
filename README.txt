OTHMAN UNIVERSE — BLUE & WHITE EDITION

1. Extract the ZIP file.
2. Open index.html in Chrome or Edge.
3. Select Admin and enter 1889.
4. Use the dashboard tabs to manage projects, news, fan messages, sections, site text, colors, custom CSS/JS, and backups.

PHOTOS: The images folder contains the generated photo sheet used for the hero, project cards, and Fan Zone. Keep the images folder beside index.html.

IMPORTANT LIMITATION: This is a local front-end edition. Changes and Fan Wall messages are stored in the browser on the device where the site is opened; they are not shared with other visitors. The 1889 code is a basic front-end gate, not secure authentication. A public multi-user site needs a server-side login and shared database.
